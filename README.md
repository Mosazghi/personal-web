# Personal Portfoilo Website

This is my personal portfolio website which can be found at [portfolio.mostes.no](https://portfolio.mostes.no/).

Built using

- [Next.js](https://nextjs.org/)
- [React](https://reactjs.org/)
- [Sanity](https://sanity.io/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Shadcn UI](https://ui.shadcn.com/)

---

The [server](./server) directory contains the C#/.NET server-side code for the old version of the website.

It's not used anymore (after migrating to Sanity for easier content management), but it's still available for reference.
